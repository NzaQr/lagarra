# La Garra

A standalone 3D claw machine game. Move the claw, use the second view to check depth, then commit the drop. The prize pile changes through physical contact and stays in place between attempts.

## Run

```sh
pnpm install
pnpm dev
```

Open the local address shown by Vite.

```sh
pnpm test
pnpm build
pnpm preview
```

The production build is in `dist/`. Serve it as a static site. No server account, external models, or API keys are needed.
